Privacy policy

PDF handling

The app checks PDF bytes locally. Its parser has no file or network access while it reads them.

Files remain only where you choose to save them.

License data

The app stores your license token and its dated result after you activate Pro.

Verification sends that token to the Sociobot billing API. The PDF parser does not use that service.

Sociobot/Dodo handles checkout as the merchant of record when its checkout registration is ready.

Website requests

The site requests its own files and public release details from the GitHub API. It does not load a tracking, analytics, font, or runtime-script service.

Successful release details stay in the browser cache for one hour.

Hosting logs may contain an IP address, browser name, and requested path for security.

Your control

Delete the app’s local data to remove the cached license.

Delete clean PDFs and JSON reports from the places where you saved them.

Questions: privacy@sociobot.in.
